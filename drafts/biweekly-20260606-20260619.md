### GPT-5.2 and GPT-5.2-Codex が廃止予定になった

GPT-5.1 Codex 系モデルの廃止予定が告知された。GPT-5.3-Codex への移行と、Enterprise の model policy 見直しが必要になる。

- なぜ重要か: 「GPT-5.2 and GPT-5.2-Codex が廃止予定になった」の廃止・移行に関わるため、既存の設定や利用モデルへの影響を確認したい更新です。
- 原典: https://github.blog/changelog/2026-06-05-gpt-5-2-and-gpt-5-2-codex-deprecated

### GitHub Copilot の Agent finder が利用可能になった

GitHub Copilot の Agent finder が利用可能になった。MCP server、skills、canvases、agents、tools を手動で選んで context を膨らませる代わりに、Copilot が作業に必要な agent 関連リソースを見つけやすくする更新。

- なぜ重要か: agent 関連リソースを手動で context に詰め込む負担を減らせるため、MCP server や skills を多用するチームほど agent 設定と context 管理が楽になります。
- 原典: https://github.blog/changelog/2026-06-17-agent-finder-for-github-copilot-now-available

### GitHub Copilot app が一般提供になった

GitHub Copilot app が macOS、Windows、Linux 向けに一般提供になった。GitHub 上の agent-driven development をデスクトップで扱うためのネイティブアプリとして位置付けられる。

- なぜ重要か: agent-driven development のデスクトップ入口が GA になったため、ブラウザーだけでなく専用アプリを前提にした日常運用を検討しやすくなります。
- 原典: https://github.blog/changelog/2026-06-17-github-copilot-app-generally-available

### GitHub Agentic Workflows が public preview になった

GitHub Agentic Workflows が public preview になった。issue triage、CI failure analysis、documentation updates など、推論を含むタスクを coding agents と workflow として自動化できるようにする更新。

- なぜ重要か: issue triage や CI failure analysis などの運用タスクを agentic workflow として定義できるため、単発の agent 実行から再利用可能な自動化へ進める候補になります。
