### code scanning alert 向け agentic autofix が public preview に

code scanning alert に対する agentic autofix が public preview になった。開発者のように関連ファイルを探索し、修正案を作ることで alert の remediation を進める。

- なぜ重要か: 単純な依存更新では済まないセキュリティ修正を agent に任せられるため、alert 対応の滞留を減らせます。
- 原典: https://github.blog/changelog/2026-07-10-agentic-autofix-for-code-scanning-alerts-in-public-preview

### VS Code と CLI の OpenTelemetry export を Enterprise で管理

organization が GitHub Copilot の OpenTelemetry（OTel）データ送信先を指定できるようになった。開発者ごとに OTEL_* 環境変数を設定せず、承認済み collector へ telemetry を送れる。

- なぜ重要か: agent telemetry の送信先を組織ポリシーとして統一できるため、observability とデータ統制を両立しやすくなります。
- 原典: https://github.blog/changelog/2026-07-08-enterprise-managed-opentelemetry-export-for-vs-code-and-cli
