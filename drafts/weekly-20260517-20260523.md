- Copilot CLI セッションのリモート操作が GA になった: GitHub Mobile と github.com、VS Code から進行中の CLI セッションを操作できる機能が一般提供になった。ターミナルを離れても agent タスクを止めずに継続できる。
- Copilot cloud agent に高速・低コストモデルが追加された: cloud agent にタスクを委任する際に利用モデルを選べるようになり、新たにシンプルなタスク向けの高速・低コストモデルが加わった。コストとタスク複雑度のバランスを取りやすくなった。
- Actions 失敗のワンクリック Copilot 修正: GitHub Actions ジョブが失敗したとき、「Fix with Copilot」ボタン一回で cloud agent に修正 PR を依頼できるようになった。CI の障害対応を Actions 画面から完結できる。
- REST API でリポジトリの CCA 設定を監査できるようになった（public preview）: 新しい「Get Copilot cloud agent configuration for a repository」エンドポイントにより、複数リポジトリの設定確認を自動化しやすくなった。
- Web 上の Copilot chat が開いているページをコンテキストとして認識するようになった: github.com で Copilot chat を開くと、現在表示中の PR・issue・コードなどが自動でコンテキストとして読み込まれる。
- Copilot Spaces API が GA になった: Copilot Spaces の作成・管理を REST API でプログラム的に行えるようになり、チームの知識共有やコンテキスト提供の仕組みを自動化しやすくなった。
- GPT-5.3-Codex が Copilot Business / Enterprise の既定モデルになった: GPT-4.1 から GPT-5.3-Codex への既定モデル切り替えが行われた。明示的にモデルを選択していない利用では応答挙動の前提が変わる。
- Web の Copilot Chat のモデル選択肢が絞り込まれた: Copilot Chat on the web で利用できるモデル選択肢が更新された。より一貫した高品質な応答を提供するためにモデルを絞り込んだ変更で、手動でモデルを選んでいた場合は選択肢が変わる可能性がある。
- Copilot usage metrics レポートのダウンロード URL 移行が完了した: レポートのダウンロード URL が Azure Front Door ドメインから GitHub 所有のカスタムドメインへの移行が完了した。旧 URL を参照する automation やスクリプトがある場合は新 URL への切り替えが必要。
