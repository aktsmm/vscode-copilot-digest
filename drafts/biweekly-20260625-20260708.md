### Gemini 2.5 Pro と Gemini 3 Flash の廃止予定

Gemini 2.5 Pro と Gemini 3 Flash は、Copilot Chat、inline edits、ask / agent modes、code completions を含む GitHub Copilot 全体験から7月31日に廃止予定である。

- なぜ重要か: 対象モデルを明示指定している利用者や組織は、期限までに代替モデルと model policy を確認する必要があります。

### GitHub Mobile で Copilot cloud agent に merge conflict 修正を依頼可能に

GitHub Mobile が Copilot cloud agent を使った pull request の merge conflict 修正に対応した。外出先でも conflict で止まった pull request を解消しやすくする。

- なぜ重要か: デスクトップへ戻らずに統合作業を前へ進められるため、モバイルからの agent 作業継続に役立ちます。
- 原典: https://github.blog/changelog/2026-07-08-github-mobile-fix-merge-conflicts-with-copilot-cloud-agent

### GitHub Mobile で Copilot CLI session の live notification に対応

GitHub Mobile の live coding agent notification が、GitHub Mobile 外で開始した remote Copilot CLI session に対応した。session が進行する間もモバイルから agent 作業とつながりやすくなる。

- なぜ重要か: terminal で始めた長時間作業の状態を外出先でも把握できるため、承認待ちや完了を見逃しにくくなります。
- 原典: https://github.blog/changelog/2026-07-08-github-mobile-live-notifications-for-copilot-cli-sessions

### GitHub Copilot アプリが全 Copilot プランで利用可能に

GitHub Copilot アプリがすべての Copilot プランで利用可能になった。GitHub アカウントでサインインすれば、macOS、Windows、Linux のデスクトップから agent 駆動開発を始められる。

- なぜ重要か: プランによる利用制約がなくなるため、デスクトップ アプリを前提にした agent 開発の展開を検討しやすくなります。
- 原典: https://github.blog/changelog/2026-07-07-github-copilot-app-available-to-all
