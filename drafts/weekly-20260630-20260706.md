## GitHub Copilot

### Gemini 2.5 Pro と Gemini 3 Flash の廃止予定

Gemini 2.5 Pro と Gemini 3 Flash は、Copilot Chat、inline edits、ask / agent modes、code completions を含む GitHub Copilot 全体験から7月31日に廃止予定である。

- なぜ重要か: 対象モデルを明示指定している利用者や組織は、期限までに代替モデルと model policy を確認する必要があります。
- 原典: https://github.blog/changelog/2026-07-02-upcoming-deprecation-of-gemini-2-5-pro-and-gemini-3-flash

### GitHub Actions 上の Copilot CLI で personal access token が不要に

GitHub Actions で GitHub Copilot CLI を実行する際、組み込み GITHUB_TOKEN を使えるようになった。personal access token を作成・保存する必要がなくなる。

- なぜ重要か: CI で Copilot CLI を使う場合の秘密情報管理が簡素化され、導入時のセキュリティ負荷を下げられます。
- 原典: https://github.blog/changelog/2026-07-02-copilot-cli-no-longer-needs-a-personal-access-token-in-github-actions

### Enterprise managed-settings.json が一般提供に

GitHub Enterprise Cloud の顧客が、選択した organization の .github-private リポジトリで管理する managed-settings.json を通じて AI の標準設定を定義できるようになった。

- なぜ重要か: AI 利用に関する組織標準をコードとして管理できるため、複数 organization への統制展開を行いやすくなります。
- 原典: https://github.blog/changelog/2026-07-01-enterprise-managed-settings-json-is-generally-available
